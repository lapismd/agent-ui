# Conflicts

Copied conflict browser, captured terms, local drafts, staging and preview without native execution.

## Usage

Mount this surface in RepositoryShell’s surface snippet. Supply immutable conflict descriptors read at the selected revision; the local draft/staging UI does not apply repository changes.

<Source code={Basic} language="tsx" />

## Anatomy

| Part                | Responsibility                                                     |
| ------------------- | ------------------------------------------------------------------ |
| Surface header      | Conflict file-browser toggle and close action.                     |
| Browser and editor  | Literal paths, captured terms and editable local resolution.       |
| Actions and preview | Stage replacement/deletion, inspect a draft and return to editing. |

## Variations

### Basic

### Empty

## Behavior and accessibility

Editing a staged replacement invalidates that stage. Preview locks the editor until Back. Changing the selected revision should remount the component so another revision cannot inherit drafts. Loading, unavailable and no-conflict states remain distinct. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.
