# JJ Log

Complete Desktop JJ Log AppShell and adaptive Column Canvas with an in-memory history controller.

## Usage

Mount the complete embedded JJ Log with a host-owned HistoryController and copy callback. Optional source and restore ports add the same controls used by Desktop.

<Source code={Basic} language="tsx" />

## Anatomy

| Part        | Responsibility                                                        |
| ----------- | --------------------------------------------------------------------- |
| AppShell    | Original bounded embedded body and optional conflict surface.         |
| Log column  | Shared header, graph, revision details and file listing.              |
| Diff column | Shared diff reader, layout/wrap controls and optional restore dialog. |

## Behavior and accessibility

Mount reads through the injected controller. Host lifetime outlives pane remounts; initialOperation and initialRevision restore exact selections. Dispose the controller only after its final owner releases it. No native transport, routing or preference storage is constructed here. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.

## Styling variables

Defaults retain the Desktop presentation. Set documented variables on an
ancestor; avoid selector overrides and dependency-internal imports. Brand and
light/dark controls remain independent in Storybook.

## Composition

Complete screens compose this same implementation. Small controls use a padded, bounded standalone preview; shell and column families retain their required production context. Docs shell previews are bounded to 40rem and flush; Canvas screens fill their parent. Host services and downstream integration remain behind the review gate.
