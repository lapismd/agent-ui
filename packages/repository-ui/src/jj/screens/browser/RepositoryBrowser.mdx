## Anatomy

| Part             | Responsibility                                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| AppShell regions | Resizable file-tree sidebar, independently scrolling content and optional host file inspector.                                 |
| Breadcrumb       | The same documented Breadcrumb component requests canonical ancestor navigation.                                               |
| Directory        | The same virtualized Directory component presents rows and optional landing documents.                                         |
| File preview     | The same File Preview component handles text, documents and unavailable data.                                                  |
| Host seams       | headerActions, directoryControls, directoryActions, rowActions, fileActions and inspector carry host-specific controls.        |
| Layout callbacks | fileTreeOpen/fileTreeWidth, inspectorWidth and their layout callbacks let hosts persist layout without package storage access. |

## Behavior and accessibility

Both sidebars resize independently by dragging their edge, Arrow keys (16px, Shift 32px), Home/End bounds and double-click reset. Bind fileTreeWidth (256px, range 208–420) and inspectorWidth (420px, range 280–800); retain layout in the host using onLayoutChange and onInspectorResize. The right inspector shares the body's semantic background and its transparent history toolbar matches the other header heights.

A stable host-owned controller is subscribed for the screen lifetime; the host
starts and closes reads. Responses are fenced by repository, operation, revision
and path. The sidebar resize handle supports drag, Arrow Left/Right, Home/End,
Shift for larger steps and double-click to reset. Layout callbacks report tree
visibility and width for optional host persistence. No mount issues mutations.

## Composition

Compose this screen with a typed RepositoryBrowserPort and a host-retained
RepositoryBrowserController. Header, directory, row, file and inspector snippets
keep app actions outside the package. File history uses the inspector; Blame replaces the file contents using the existing
production history components against the same in-memory file contents. Review
this slice before adding repository overview or workspace transfers.
