# Branches

Source-adapted JJ Store Branches screen with independently resizable Branches, Revisions and Diff columns.

## Usage

Create one host-retained RepositoryBranchesController with a captured-reference read port, HistoryReader and feedback sink. Call controller.open with the exact repository/operation before or after mounting; mounting subscribes only. The host closes the controller after unmount. Pass a canvas from createBranchesCanvas for optional host persistence; the host then owns its disposal.

## Behavior and accessibility

References resolve before graph reads. Single targets use their exact ancestry, conflicted references use the union and deleted references use none(). Immutable pins, graph clocks and continuation cursors remain bound to the selected reference. Changing references clears revision/files/diff. Working copies open their exact recorded commit. The controller rejects mismatched pins, duplicate references, repeated cursors and stale replies, and aborts/drains owned reads on close. Header slots, branch actions, revision/file actions and diff menus request host effects only. No mounting mutation, routes, storage, credentials or native access is built in. Empty/unavailable states use shadcn Empty with an icon and retry when applicable.

## Composition

Files is the repository overview. Branches reuses the existing history/controller/diff families; Workspace and downstream adoption remain separate review slices. Host-owned route or operation changes call controller.open with the new pin. Optional typed slots are branchHeaderActions, revisionHeaderActions, branchActions, revisionActions, fileActions, diffActions and allChangesActions. Diff settings, menus and totals use the same RepositoryDiffPreferences contract as both logs.
