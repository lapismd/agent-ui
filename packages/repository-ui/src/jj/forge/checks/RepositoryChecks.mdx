# Checks

Shared revision-aware checks from JJ Store, used inside pull requests and standalone workflow or deployment details.

## Usage

The host supplies observations and owns refresh, permissions and adapter lifetime.

## Behavior and accessibility

Keyboard-operable disclosures expose expanded state. Display options switch
between grouped and flat lists without reading a provider or writing. Each status
group collapses independently. Unknown, stale and incomplete data never claim
that the current revision has passed. Refresh emits one explicit host callback;
mounting and display changes emit none. Missing refresh capability stays disabled.

## API

<ArgTypes of={Stories} />

Public exports include RepositoryCheck, RepositoryCheckState and
RepositoryChecksSnapshot. A snapshot carries its SHA, completeness and identified
results; the host separately supplies currentSha.

## Composition

RepositoryPullRequestChecks only adapts the host review's exact scoped refresh
request to RepositoryChecks. The same component supports non-PR hosts without
copying check markup or controller authority. Ring and row are private parts of
this family. Stories remain visual-pending.
