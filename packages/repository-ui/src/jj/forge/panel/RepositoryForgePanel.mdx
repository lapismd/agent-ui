## Behavior and accessibility

The title disclosure is transparent and keyboard-operable when attached. It is
inert while floating. Float opens the same content in a resizable, draggable
Design Core window with the owning theme. Dock and Escape retain its state.
Expanding, docking and floating never execute a provider action. The host owns
controller lifetime and applicable actions; merge controls belong to PR content.

## API

<ArgTypes of={Stories} />

Optional leading/context/action snippets supply domain content without
recreating the frame. Controlled expansion delegates to onExpandedChange;
onClose belongs to the host. The panel never fabricates a PR for a workflow.

## Composition

RepositoryPullRequest composes this production frame around its editor, checks
and merge footer. Other forge hosts compose it around the same RepositoryChecks
and their own workflow/deployment metadata. RepositoryDetachablePanel is a
private part of this family. All stories remain visual-pending.
