# Comparison picker

Explicit parent comparison with exact IDs, metadata, search and unavailable choices.

## Usage

Supply the exact recorded parent IDs and their available commit cards. Use this for a merge comparison rather than choosing a convenient branch tip.

<Source code={Basic} language="tsx" />

## Anatomy

| Part           | Responsibility                                                 |
| -------------- | -------------------------------------------------------------- |
| Trigger        | Current comparison target.                                     |
| Search list    | Author, description, Git/JJ IDs and tags for recorded parents. |
| Preview footer | Metadata for the highlighted option.                           |

## Variations

### Basic

The ordinary populated presentation with recorded identities and explicit callbacks.

<Canvas of={Stories.Loading} />

### MissingParent

## Behavior and accessibility

Only supplied parents can be selected. Missing cards remain labelled by their exact ID while the host loads metadata. Search and keyboard navigation must not silently choose a comparison. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.

## Styling variables

Defaults retain the Desktop presentation. Set documented variables on an
ancestor; avoid selector overrides and dependency-internal imports. Brand and
light/dark controls remain independent in Storybook.
