# Diff

Recorded diff with unified/split rendering, explicit unavailable content and source controls.

## Usage

Pass a LocalFileDiffChange returned for the current pinned from/to/path tuple. This wrapper maps recorded text hunks to the public Design Core FileDiff.

<Source code={Basic} language="tsx" />

## Anatomy

| Part              | Responsibility                                                |
| ----------------- | ------------------------------------------------------------- |
| Preview region    | Accessible Changes to path label.                             |
| Diff reader       | Unified or split panes with controlled wrapping.              |
| Unavailable state | Empty with an icon for binary, structural or refused content. |

## Variations

### Basic

The ordinary populated presentation with recorded identities and explicit callbacks.

### Split

### Unavailable

A refused or failed read, distinct from a successful empty result. The production Empty state names the failure and leaves explicit recovery reachable.

### Complex

Multiple changed regions separated by retained context use the ordinary diff reader. Long unchanged sections collapse with incremental or full reveal controls in unified and split views. Either split pane controls the same expanded context in both panes.

## Behavior and accessibility

Unavailable is distinct from an empty textual diff. Split mode fills its bounded parent; compact previews fit their content. The shared Design Core reader hides long unchanged sections in both layouts; use the top/bottom incremental controls or Show all, then Hide to collapse the section again. Split panes retain old/new line numbers and share expansion state. File authorization and content retrieval remain host-owned. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.
