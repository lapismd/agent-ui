# Revision graph

Original revision/operation graph rows, tags, author cards and row selection.

## Usage

Convert pinned commit or operation records with commitRows/operationRows, then render this graph in a bounded log body. The selectedFiles snippet puts the selected revision’s file controls directly below its row.

## Anatomy

| Part             | Responsibility                                                            |
| ---------------- | ------------------------------------------------------------------------- |
| Graph lanes      | Original connector geometry and continuation lanes.                       |
| Revision row     | Author, description, timestamps, tags and independent identifier actions. |
| Expanded content | The selected row’s production changed-file controls.                      |

## Behavior and accessibility

The optional `rowActions` snippet receives the recorded revision, including `authorEmail` when supplied. This supports stack rows without fabricating transport commit objects.

The optional `draggable`, `rowDropState` and `rowDropPlacement` callbacks expose
native row drag sources and transient destination/insertion feedback. They
default to absent, so ordinary history rows retain their selection behavior.
Workspace event delegation uses each row's recorded `data-revision-id`; the
graph itself does not execute transfers or own their policy.

Stacks use `continuous` to inset selected-file content beside the graph lanes,
with zero top and half-rem right/bottom padding, matching JJ Store's stacked cards.
Its SVG connectors span the full expanded item height beside the file card in
both Stacks and Workspace.

Selection delegates the full event ID. Author/profile and copy actions remain independent of row selection. An empty graph renders Empty with an icon and does not fabricate a revision. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.

Known conflicts display a Conflicted badge and a subtle destructive theme tint,
including during selection and hover. Row content follows jj-store’s repositoryLogContentLeft for each row, so avatars move with the active lanes rather than aligning to a global column. The graph reserves 20rem beside its lanes and scrolls when constrained. Neutral operation chips use an opaque
secondary surface so they remain distinct on selected rows; Snapshot, Merge and
workspace chips carry their corresponding icons.
