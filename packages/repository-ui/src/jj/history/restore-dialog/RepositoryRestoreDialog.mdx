# Restore dialog

Original guarded file/vault restore preview and retained-request recovery confirmation.

## Usage

Prepare a RestoreController from an explicit restore action. The host supplies preview/apply services and an admission guard; mounting the dialog never applies a restore.

<Source code={Basic} language="tsx" />

## Anatomy

| Part         | Responsibility                                                                |
| ------------ | ----------------------------------------------------------------------------- |
| Confirmation | Exact file or vault preview and guarded action.                               |
| Recovery     | Original request retained after an unknown outcome, without automatic replay. |

## Variations

### Basic

The ordinary populated presentation with recorded identities and explicit callbacks.

### Vault

<Canvas of={Stories.Vault} />

## Behavior and accessibility

Closing a preview cancels presentation only. Apply uses the exact preview proof and original request ID. Persist pending requests in the host and recover them explicitly; the library does not infer execution success. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.

## Styling variables

Defaults retain the Desktop presentation. Set documented variables on an
ancestor; avoid selector overrides and dependency-internal imports. Brand and
