# Workspace picker

Recorded workspace and repository overview selection without inferring native authority.

## Usage

Pass optional `entries` with exact `id`, display `name`, `description` and `disabled` metadata to reuse this Command View selector for named workspaces. Set `includeOverview={false}` for a required workspace and configure its trigger `label` and `variant`. No synthetic commit is needed.

Supply workspace names recorded at the current operation. Null selects the repository overview; a string selects that exact recorded workspace.

## Behavior and accessibility

onOpen can load metadata through the existing pinned reader. Disabled prevents changes during unavailable admission; a workspace label never creates native authority. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.
