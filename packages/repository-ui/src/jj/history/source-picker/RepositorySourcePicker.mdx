# Source picker

Explicit host-owned choice between automatic history and the original repository.

## Usage

Provide a HistorySourcePicker owned by the host. Automatic vault checkpoints and original repository history remain distinct data sources; selecting one delegates admission and routing.

<Source code={Basic} language="tsx" />

## Anatomy

| Part               | Responsibility                                            |
| ------------------ | --------------------------------------------------------- |
| Trigger            | Compact Backup or Original label.                         |
| Source list        | Command View choices and filled selection icon.           |
| Unavailable notice | Empty with icon when no original repository is available. |

## Behavior and accessibility

Opening calls picker.load; failures go to picker.report. Selecting another source calls picker.select once. No component initializes or mutates a repository. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.

## Styling variables

Defaults retain the Desktop presentation. Set documented variables on an
ancestor; avoid selector overrides and dependency-internal imports. Brand and
light/dark controls remain independent in Storybook.
