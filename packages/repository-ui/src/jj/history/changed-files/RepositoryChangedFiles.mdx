# Changed files

Original bounded tree/list of changed paths with explicit selection and paging.

## Usage

Supply recorded FileListingFile entries for one exact comparison. Place the component beneath the selected revision or operation row; standalone stories show its own boundary on a padded surface.

<Source code={Basic} language="tsx" />

## Anatomy

| Part         | Responsibility                                            |
| ------------ | --------------------------------------------------------- |
| Header       | Changed-file count and tree/list/package view toggle.     |
| File listing | Public FileListing with selected path and bounded paging. |

## Behavior and accessibility

onSelect returns the literal path to the owning controller. onMore requests another page; initialLoading and loading are distinct. An empty comparison uses Empty with an icon. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.

The optional `actions` snippet adds host controls beside the view-mode toggle.
It uses the same header in complete JJ Log screens.

## Styling variables
