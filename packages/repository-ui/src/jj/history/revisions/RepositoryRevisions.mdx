# Revision details

The graph and selected revision body with message, parent comparison and changed paths.

## Usage

Use this compound body with a HistoryController snapshot. It is the production JJ Log body: graph rows, expanded message, exact parent picker and changed files.

<Source code={Basic} language="tsx" />

## Anatomy

| Part                 | Responsibility                                                      |
| -------------------- | ------------------------------------------------------------------- |
| Graph                | Pinned revisions and source geometry.                               |
| Revision body        | Commit message and optional conflict, evolution or restore actions. |
| Comparison and files | Recorded parent pair and bounded changed paths.                     |

## Behavior and accessibility

Selecting a revision expands it; selecting it again clears that selection and fences stale reads. Merge revisions require an explicit parent. The controller, not the view, owns reads and cleanup. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.

Long commit bodies offer View more and View less. Focusing a Markdown link reveals
the full message. The Markdown preview is transparent by default, retaining the
surrounding message panel background through Mira's public preview token.

The complete JJ Log places the shared limit notice beneath its scrolling body.
Standalone revision bodies include it by default; `showLimitNotice={false}` lets
an owning column place that same notice in its fixed footer.
