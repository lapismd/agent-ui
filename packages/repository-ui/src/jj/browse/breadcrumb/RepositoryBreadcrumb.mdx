# Breadcrumb

Navigate from the host repository identity through the Files root and canonical path segments. The current segment is text; ancestor segments request navigation through callbacks.

## Usage

Navigate from the host repository identity through the Files root and canonical path segments. The current segment is text; ancestor segments request navigation through callbacks.

<Source code={Basic} language="tsx" />

## Anatomy

| Part                | Responsibility                                                                                 |
| ------------------- | ---------------------------------------------------------------------------------------------- |
| Repository identity | Uses the supplied display name; an optional callback opens the owning app destination.         |
| Files root          | Returns to the root directory without changing the selected operation or revision.             |
| Path segments       | Each ancestor retains its complete canonical path; the final segment exposes the current page. |

## Behavior and accessibility

The navigation landmark is named Repository path. Ancestor links request their
complete canonical directory path, while the current segment uses aria-current.
The optional repository link calls the host without changing the repository pin.
Long labels truncate without hiding their accessible names.

## Composition

Use the breadcrumb above a RepositoryDirectory or RepositoryFilePreview. The
complete RepositoryBrowser supplies its current path and wires ancestor links
to the host-retained controller; standalone hosts may supply their own routing.
