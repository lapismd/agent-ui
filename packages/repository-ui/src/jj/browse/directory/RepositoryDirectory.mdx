## Behavior and accessibility

The metadata ellipsis toggles the same local recorded commit description used by File History, directly beneath its row inside the same card, with a thin divider, muted body surface, an 8px top and horizontal inset, and no bottom padding or outer margins. Long descriptions offer View more/View less; Markdown stays transparent inside the parent panel. The ellipsis keeps a stronger semantic background while expanded. Disclosure does not invoke commit navigation, change the pin or issue a repository read.

File and folder buttons have explicit action names. Arrow Up/Down and Home/End
move focus between loaded rows, with virtual scrolling retaining focus. The
parent row requests its canonical ancestor. Paging and retry are explicit host
requests; snapshot attribution is distinct from a recorded path change. The
summary commit opens only when a host callback is available. The shared Design
Core PanelToggle controls sidebar visibility and exposes its expanded state.
