# Reference Picker

Copy of JJ Store's snapshot command view, with host-owned bookmark/change identities.

## Usage

Pass a controlled value and loaded choices at the current operation. Search uses labels and host-supplied commit, author or change keywords. Selection returns the complete choice; zero or multiple targets stay explicit for host resolution.

## Anatomy

| Part           | Responsibility                                                         |
| -------------- | ---------------------------------------------------------------------- |
| Trigger        | Current host label, branch icon and open state.                        |
| Popover header | Switch snapshot title and keyboard-accessible close action.            |
| Command input  | Filter supplied labels, commit/change identities and keywords.         |
| Kind filters   | Bookmarks and Changes retain the source command-view layout.           |
| Virtual rows   | Bounded reference rendering, selected checkmark and continuation.      |
| Status         | Icon-bearing Empty and unavailable states, loading and optional retry. |

## Behavior and accessibility

The public Command View uses grid, rowgroup, row and gridcell roles, with the search combobox advertising a grid popup. This allows independent avatar, timestamp and Git/JJ buttons inside change rows without nesting controls in a listbox option. Arrow keys and Enter retain Command View navigation and selection; clipboard/profile actions do not select a snapshot.

The trigger exposes combobox state. Command View owns the search input, option navigation and keyboard selection; Escape returns focus through the public Popover. Choosing a row closes the command view and calls the host once with its complete identity. Queries do not alter repository pins. The host owns target resolution, reads, cursor scope and optional continuation/retry; mounting this control never mutates repository state.

## Composition

The complete Files screen supplies this picker through RepositoryBrowser's directoryControls slot. Hosts may place the same control in other repository headers. Keep authority to resolve a chosen bookmark/change, route to a revision or persist preferences in the application adapter.
