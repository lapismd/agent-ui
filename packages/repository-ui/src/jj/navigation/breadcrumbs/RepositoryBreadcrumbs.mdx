Context ancestry with an optional repository picker root and explicit host navigation.

Use the public component with host-owned values and callbacks. Navigation does not grant repository access.

## Behavior and accessibility

Repository choices use exact host-issued IDs and never change authority on mount.
Command View supports search and keyboard selection; Escape restores trigger focus.
Unavailable choices cannot be selected. Native folder opening is an explicit host callback.
Breadcrumb parents use real links and retain modified-click behavior. Their final item marks
current location. Global ancestry omits the repository root to avoid implying scope.
Page tabs move overflow into More and retain selected state. Stacks replaces the outer
repository tab set; the host owns Back and preserves the current page when switching roots.
Complete canvases opt out of body scrolling and own their scroll containers.

## Composition

Compose these components in the native app shell or shared complete screen. Pass the same
RepositoryPicker as the first breadcrumb item on repository routes; show it separately
from global breadcrumbs. Keep host selection, persistence and notifications in adapters.
