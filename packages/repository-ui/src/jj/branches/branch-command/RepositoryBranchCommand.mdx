# Branch Command

Source-adapted JJ Store bookmark command view with working copies, captured metadata, filters and isolated host actions.

## Usage

Pass captured bookmarks and working copies. Selection returns an opaque bookmarkKey; resolve it against the same loaded page. Timestamps and now are Unix seconds. Local and remote names retain distinct identities.

<Source code={Basic} language="tsx" />

## Anatomy

| Part               | Responsibility                                                              |
| ------------------ | --------------------------------------------------------------------------- |
| Working-copy cards | Recorded workspace, description and attribution.                            |
| Filters and search | Search loaded branch metadata without changing history scope.               |
| Bookmark cards     | Exact local/remote identities, default/workspace/conflicted/deleted status. |
| Virtual rows       | Shared bounded rendering and host continuation.                             |

## Behavior and accessibility

Command View owns search and arrow/Enter navigation. All, Workspace and Conflicted filters affect loaded cards only. The host supplies bounded continuation; filtering never changes the captured operation. Avatar and custom action activation stay separate from reference selection. Missing descriptions and deleted/multiple targets remain explicit. Working-copy cards retain their workspace identity.
