# Identifiers

Exact commit/change identifiers with compact, expanded, keyboard and copy feedback.

## Usage

Show full commit and native JJ change identifiers without turning one into the other. Choose inline placement beside metadata or overlay placement in a positioned owner.

<Source code={Basic} language="tsx" />

## Anatomy

| Part              | Responsibility                                                       |
| ----------------- | -------------------------------------------------------------------- |
| Commit identifier | Compact Git SHA with full accessible value and copy control.         |
| Change identifier | Native reverse-hex change ID, independently expandable and copyable. |

## Variations

## Behavior and accessibility

Pass the exact host-issued strings. Copy uses the injected promise and reports failure through the optional error callback; displaying an ID grants no repository access. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.
