# Author avatar

Recorded author identity with independent hover/focus profile activation.

## Usage

Supply the recorded author name and email. Pass an optional avatarUrl resolved by the host, or call provideRepositoryAuthorAvatars during host component initialization to provide a cached resolver to all descendant graph/blame avatars; email identifies the profile but does not initiate a lookup inside this component.

## Anatomy

| Part           | Responsibility                                                                      |
| -------------- | ----------------------------------------------------------------------------------- |
| Avatar trigger | Public AuthorCard with initials, deterministic fallback colour and selected size.   |
| Profile card   | Hover or focus opens the name and email without selecting the surrounding revision. |

## Behavior and accessibility

The trigger stops row activation from pointer and Enter/Space events. Sizes use the public Avatar scale. The Gravatar story hashes dev@lapis.md in the catalog host and supplies the resulting URL; an unavailable image retains initials. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.
