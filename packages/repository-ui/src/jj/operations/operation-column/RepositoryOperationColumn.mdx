# Operation details

Original operation metadata and comparison inspector with files and recorded targets.

## Usage

Place the inspector beside the operation list in the same ColumnCanvas.Root. Supply the OperationController snapshot and keep its diff column reachable through compact navigation.

| Part           | Responsibility                                                                           |

## Behavior and accessibility

Long recorded commands collapse to a nine-rem preview. View more/View less
preserves the exact captured command, exposes expansion state and resets when
the selected command changes; short commands need no toggle.

Operation metadata and the file diff share one column. A file selection retains the original pin and exact revision endpoints. Collapsing metadata must preserve the selected diff and its vertical fill. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.

## Styling variables

Defaults retain the Desktop presentation. Set documented variables on an
ancestor; avoid selector overrides and dependency-internal imports. Brand and
light/dark controls remain independent in Storybook.
