# Pin picker

Full pinned-operation identity with searchable recorded operation metadata.

## Usage

Supply the current pin alongside observed operation heads. Keep a historical pin in the choices even when refresh discovers another head.

## Behavior and accessibility

Selecting an option delegates its full operation ID. Opening/searching performs no repository writes. Missing metadata must not invent a Git commit or JJ change identity. Keyboard focus, labelled controls and explicit retry actions follow the shared Design Core primitives.
