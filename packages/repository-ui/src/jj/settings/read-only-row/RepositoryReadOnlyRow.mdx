# Read only row

JJ Store's `StoreReadOnlyRow`, ported with its markup, styles, open control and
copy feedback. Native folder selection and navigation remain host callbacks.

## Usage

<Source code={Basic} language="tsx" />

## Anatomy

A definition row contains an optional icon, label and description, followed by
the value and open/copy controls. Long copyable values truncate visually while
retaining the complete title, accessible action label and clipboard text.

## Behavior and accessibility

Use inside `dl.store-settings__rows`, or set `standalone` to render its own `dl`.
Buttons support keyboard operation. Copy owns the full-row hit target; the open
control remains independent. A status region announces success or failure.
Changing the value or disposing the row invalidates late copy feedback. Missing
values use `emptyLabel` and omit open/copy controls. `openDisabled` gates only
the host action; available text remains copyable. Mounting never calls the host.
`loading` renders the shared Skeleton in the retained label/value row, announces
its loading label, and omits open/copy controls until the value is ready.

## API

<ArgTypes of={Stories} />

`value` is the exact copy source; `display` changes only its visual formatting.
`children` supplies custom value content in a block container, including public
MarkdownContent for rich read-only values. `onOpen`, `openLabel`, `openDisabled`
bind host navigation. `copyable` enables copying without an open action.

## Composition

The Settings page Basic story and JJ Desktop Repository settings use this same
row for repository identity, folder path and storage information. Settings
controllers, admission and native dialogs remain application-owned.
