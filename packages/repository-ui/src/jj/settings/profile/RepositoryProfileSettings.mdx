## Behavior and accessibility

All controls retain accessible labels and keyboard focus. Pending reads use public Skeleton and unavailable reads use icon Empty. Profile drafts and exact unknown requests survive navigation; only explicit Save, status inspection and proven-not-received retry invoke host ports. Conflict reconciliation retains the authored draft. Uploaded media resolves through host-owned immutable references.

## API

<ArgTypes />

`RepositoryProfileController` receives `ProfilePort`: read, draft, save, inspect and normalized upload. The host owns its lifetime and error notifications. `PersonalProfile` preserves principal identity separately from editable details. `RepositorySettingsField` and `RepositorySettingsFooter` are the original JJ Store settings row/footer primitives, also available from `/settings`.

## Composition

Mount this completed screen in the application body and retain its controller when opening other settings or repositories. Compose the profile menu in the left AppShell sidebar footer.
