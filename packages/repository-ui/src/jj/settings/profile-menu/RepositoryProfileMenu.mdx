## Behavior and accessibility

All controls retain accessible labels and keyboard focus. Pending reads use public Skeleton and unavailable reads use icon Empty. Profile drafts and exact unknown requests survive navigation; only explicit Save, status inspection and proven-not-received retry invoke host ports. Conflict reconciliation retains the authored draft. Uploaded media resolves through host-owned immutable references.

## API

<ArgTypes />

`profile` and `avatarUrl` are host-supplied presentation. `onProfile` and `onSettings` run after menu dismissal. `compact`, `loading` and `onRetry` preserve collapsed-sidebar, initial-read and recovery states.

## Composition

Mount inside AppShell.Sidebar.Footer and keep the app version below it. The host opens the shared Profile settings page and retains installation-scoped state across repository changes.
