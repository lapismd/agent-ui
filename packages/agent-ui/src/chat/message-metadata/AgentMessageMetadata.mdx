# Message metadata

Retry, recipient delivery and response-copy actions composed inside the shared metadata row.

## Usage

Pass captured item presentation and explicit host actions. The Transcript owns time and outcome text; this component supplies the same reusable action content to that row.

<Source code={Basic} language="tsx" />

## Anatomy

Time and outcome come from Design Core MessageMetadata; these copied Desktop actions provide retry, recipient badges and response copy.

## Behavior and accessibility

Retry requires an explicit click and a host callback. Busy state disables retry. Captured recipient states never imply successful delivery. The warning stays attached below the composer in the error example.
