# Tool inspector

The original AppShell tool-detail surface with formatted, source and capture views.

## Usage

Open this surface from onInspectTool and retain the actual opener element. Pass the same TranscriptController as the body so exact comments and disclosure state are shared. Close from onDismiss and restore focus to the opener.

<Source code={Basic} language="tsx" />

## Anatomy

| Part          | Responsibility                                       |
| ------------- | ---------------------------------------------------- |
| Surface layer | AppShell overlay with return focus and dismissal.    |
| Header        | Captured tool title, view selector and close button. |
| Body readers  | Formatted blocks or the immutable raw capture.       |

## Behavior and accessibility

The view selector offers Preview, Source and Capture for Markdown tools, and Formatted/Source for other tools. Escape dismisses the AppShell surface. Switching raw views changes presentation only; captured text and revision remain unchanged.

## Styling variables

Set variables on an ancestor of the component. Defaults retain the original
Desktop geometry. Use the brand dropdown for Default/Lapis and the separate
light/dark button for color mode. Components inherit semantic Design Core colors.
The table identifies the package that owns each variable; styles load with the
