# Turn changes

Original Desktop saved-turn summary with file listing, revision identifiers, rail, preview and undo dialogs.

## Usage

Create one host-owned AgentChangesController with an injected port. Pass it through transcriptOptions.changes on AgentChatScreen to compose the summary, changes button, rail, file preview and dialogs. Hosts own immutable checkpoint identities and every repository effect.

<Source code={Basic} language="tsx" />

## Anatomy

The summary card uses FileListing and FileChangeStats. Its header exposes view and undo actions; the footer exposes revision IDs, expansion and tree/list controls. The AppShell rail and main inspector retain Desktop geometry.

## Behavior and accessibility

Visible cards request read-only comparisons. Undo first requests a preview and requires confirmation of that exact host request. Unavailable comparisons and files expose retry; incomplete and bounded captures disable whole-turn undo. Dispose the controller with the host.
