# Message composer

The copied MarkdownComposer adapter used by the production Agent transcript.

## Usage

Bind value to the host-retained draft and forward onSend to the same TranscriptController used by the footer. Bind documentActions and render that snippet once in AgentChatFooter when the formatting toolbar is docked.

<Source code={Basic} language="tsx" />

## Anatomy

| Part                  | Responsibility                                         |
| --------------------- | ------------------------------------------------------ |
| Before or drawer slot | Attachment and pending-request content.                |
| Markdown editor       | Controlled Mira input with the original avatar gutter. |
| Document actions      | Bindable formatting snippet for the persistent footer. |

### Error

Host feedback retains the authored draft.
For a refused send, pass `sendError` only for the exact retained submission.
Document mode renders the shared MessageMetadata beneath the draft, aligned
with its prose. The transcript keeps Classic feedback in its existing footer.
Unknown outcomes use retained-request recovery feedback, never a resend action.

<Canvas of={Stories.Error} />

## Behavior and accessibility

Enter inserts a newline in both presentations; Ctrl/Command+Enter requests send. disabled blocks submission. The host clears the draft only after acknowledgement. Supply extensions and triggers through the public editor APIs for application-specific references.

## Styling variables

Desktop geometry. Use the brand dropdown for Default/Lapis and the separate
