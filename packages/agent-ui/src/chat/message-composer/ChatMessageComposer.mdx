# Message composer

The copied MarkdownComposer adapter used by the production Agent transcript.

## Usage

Bind value to the host-retained draft and forward onSend to the same TranscriptController used by the footer. Bind documentActions and render that snippet once in AgentChatFooter when the formatting toolbar is docked.

<Source code={Basic} language="tsx" />

## Anatomy

| Part                  | Responsibility                                         |
| --------------------- | ------------------------------------------------------ |
| Before or drawer slot | Attachment and pending-request content.                |
| Markdown editor       | Controlled Mira input with the original avatar gutter. |
| Document actions      | Bindable formatting snippet for the persistent footer. |

### Error

Host feedback retains the authored draft.
For a refused send, pass `sendError` only for the exact retained submission.
Document mode renders the shared MessageMetadata beneath the draft, aligned
with its prose. The transcript keeps Classic feedback in its existing footer.
Unknown outcomes use retained-request recovery feedback, never a resend action.

### Paired references

The composer and Markdown preview render the same source with shared Design Core
InlineReference/ReferenceChip, icons and avatars. The fixture includes people,
agents, repositories, projects, tasks, channels, Unicode/custom emoji, spoilers,
formatting, tables and code. `@`, `#`, `:` and `/` demonstrate cancellable suggestions.
People/agent references retain jj-store's filled author chip. The composer offers
exact token removal; the Markdown preview keeps the same chip without removal.
`references.getPopover` optionally supplies host profile content and actions.
GitHub and Forgejo links use Mira’s public `inlineLinksExtension()` in both
composer and preview. A third, plain Mira panel renders the same source without
Chat extensions for comparison. Content typography, spacing and indentation stay
stock; the composer removes note centering and disables line numbers through
public configuration. Custom chip styling keeps removal inside each chip and
omits link underlines.

## Behavior and accessibility

Enter inserts a newline in both presentations; Ctrl/Command+Enter requests send. disabled blocks submission. The host clears the draft only after acknowledgement. Supply extensions, triggers, referenceSources, references, customEmojis and emojiText through public editor APIs. The complete Transcript forwards these same hooks to its composer and inline comment editors. Host codecs own stable identities and serialization; navigation never implies delivery. Legacy people.value insertions remain literal.
