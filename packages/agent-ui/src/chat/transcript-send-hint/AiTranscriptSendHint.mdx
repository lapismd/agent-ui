# Send feedback

The original keyboard hint and host delivery feedback below the transcript.

## Usage

Pass the presentation panel and current host error. Composer status takes priority over the fallback error. This keeps feedback consistent with the footer while the draft stays in the owning controller.

<Source code={Basic} language="tsx" />

## Anatomy

| Shortcut hint | Ctrl/Command+Enter send guidance.            |

## Behavior and accessibility

Feedback never triggers a retry or clears authored text. Unknown or refused submissions stay under host control. This component supplies presentation only; status recovery belongs to the controller and port.

## Styling variables

Set variables on an ancestor of the component. Defaults retain the original
Desktop geometry. Use the brand dropdown for Default/Lapis and the separate
light/dark button for color mode. Components inherit semantic Design Core colors.
