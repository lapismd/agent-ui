# Send feedback

Keyboard send guidance below the transcript; attached feedback belongs to the composer.

## Usage

Render AgentSendHint beside the fixed actions. Send errors and warnings through ChatMessageComposer.status or AgentTranscriptOptions.composer.status; the hint takes no controller or error props.

## Behavior and accessibility

The hint does not render an alert or status banner. Composer feedback never triggers a retry or clears authored text. Unknown or refused submissions stay under host control. This component supplies presentation only; status recovery belongs to the controller and port.
