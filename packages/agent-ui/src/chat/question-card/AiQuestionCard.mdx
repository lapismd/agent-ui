# Question card

Host-requested answers with advertised choices, optional free text and explicit submission.

## Usage

Supply UserInputRequest and send the returned UserInputAnswers with the exact request identity. Answers are keyed by question ID. Option answers preserve their labels as required by this public contract.

<Source code={Basic} language="tsx" />

## Anatomy

| Part             | Responsibility                                                |
| ---------------- | ------------------------------------------------------------- |
| Fieldset         | One named group for each question.                            |
| Choices or input | Advertised options, optional Other, or a direct text input.   |
| Submit           | Enabled only when every required answer has nonempty content. |

## Behavior and accessibility

Selecting a choice exposes aria-pressed. Other reveals a named answer input. Secret questions use a password field. The card trims answers at explicit submit and never changes host state on mount.

## Styling variables

Set variables on an ancestor of the component. Defaults retain the original
Desktop geometry. Use the brand dropdown for Default/Lapis and the separate
light/dark button for color mode. Components inherit semantic Design Core colors.
The table identifies the package that owns each variable; styles load with the
