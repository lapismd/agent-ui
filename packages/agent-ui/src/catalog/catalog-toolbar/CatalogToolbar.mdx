# Toolbar

The copied catalog search and disclosure toolbar used by the complete screen.

## Usage

Create AgentCatalogController from the owning AgentUiController. Place the toolbar in the original ai-catalog root, and retain that controller while the host switches screens. Search changes are presentation state; host mutations stay explicit.

<Source code={Basic} language="tsx" />

## Anatomy

| Part    | Responsibility                       |
| ------- | ------------------------------------ |
| Search  | Named controlled search field.       |
| Actions | Original folder disclosure controls. |

## Variations

## Behavior and accessibility

Search filters the catalog by host-supplied labels. Expand/collapse changes presentation only and cannot enable a tool or change the host runtime.

## Styling variables

Set variables on an ancestor of the component. Defaults retain the original
Desktop geometry. Use the brand dropdown for Default/Lapis and the separate
light/dark button for color mode. Components inherit semantic Design Core colors.
The table identifies the package that owns each variable; styles load with the
owning component family.
