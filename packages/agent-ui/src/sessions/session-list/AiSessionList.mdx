# Session list

Grouped conversation rows with active selection, loading skeletons and an empty state.

## Usage

Supply a stable item ID and a host-owned activeId. onSelect requests navigation; keep the controller alive while switching sessions. The list automatically reveals the selected group.

<Source code={Basic} language="tsx" />

## Anatomy

| Part                     | Responsibility                                        |
| ------------------------ | ----------------------------------------------------- |
| Group disclosure         | Keyboard-operable folder toggle.                      |
| Session row              | Identity, title and status for one stable session ID. |
| Loading or empty content | Mutually exclusive feedback for the host read state.  |

## Behavior and accessibility

busy disables row selection. loading presents a named busy status. Empty text is supplied by the host. Folder disclosure state belongs to this mounted list; session selection belongs to the host.

## Styling variables

Set variables on an ancestor of the component. Defaults retain the original
Desktop geometry. Use the brand dropdown for Default/Lapis and the separate
light/dark button for color mode. Components inherit semantic Design Core colors.
The table identifies the package that owns each variable; styles load with the
owning component family.
