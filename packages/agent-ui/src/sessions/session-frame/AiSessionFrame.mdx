# Session frame

The production embedded AppShell boundary used by Agent chat and recorded conversations.

## Usage

Give the frame a bounded parent height. Bind height to AgentSessionThread so its header, scrolling body and footer share the measured AppShell body. Supply navigation, bodySidebar and toolInspector snippets to reuse the original shell topology.

<Source code={Basic} language="tsx" />

## Anatomy

| Part                        | Responsibility                                                    |
| --------------------------- | ----------------------------------------------------------------- |
| AppShell root and main      | Embedded desktop shell with no invented outer application chrome. |
| Body content                | Measured main region for AgentSessionThread.                      |
| Sidebar and inspector slots | Host-controlled companion regions and tool surface.               |

## Behavior and accessibility

ResizeObserver publishes body dimensions and disconnects on teardown. Compact layout follows the original 640px body-width boundary. Hiding main content makes it inert while an inspector owns that region.

## Styling variables

Set variables on an ancestor of the component. Defaults retain the original
Desktop geometry. Use the brand dropdown for Default/Lapis and the separate
light/dark button for color mode. Components inherit semantic Design Core colors.
The table identifies the package that owns each variable; styles load with the
owning component family.
