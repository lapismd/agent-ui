# Session header

The original session header: conversation toggle, identity, title, status and host action slots.

## Usage

Place the header in AgentSessionThread, or compose it with AgentSessionFrame when the host owns the body. Bind expanded state to the same session list that the toggle reveals. Complete screens use this exact header.

<Source code={Basic} language="tsx" />

## Anatomy

| Part                 | Responsibility                                      |
| -------------------- | --------------------------------------------------- |
| Toggle               | Opens the host-owned conversation list.             |
| Identity and heading | Harness avatar, truncated title and status.         |
| Actions              | Host snippet for view selection or session actions. |

## Behavior and accessibility

The conversation control exposes its pressed state and retains its accessible label. Long titles truncate without displacing actions. The header owns no navigation or session lifetime.

## Styling variables

Set variables on an ancestor of the component. Defaults retain the original
Desktop geometry. Use the brand dropdown for Default/Lapis and the separate
light/dark button for color mode. Components inherit semantic Design Core colors.
The table identifies the package that owns each variable; styles load with the
owning component family.
