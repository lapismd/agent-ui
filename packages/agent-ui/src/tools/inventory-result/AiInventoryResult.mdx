# AiInventoryResult

Original Desktop skills and tools discovery result.

## Usage

Pass a normalized inventory from the host. Reuse this renderer for the Desktop /skills and /tools registered command results.

<Source code={Basic} language="tsx" />

## Anatomy

Each row contains the captured name, description and optional open action. Empty inventories use the public Empty primitive.

## Behavior and accessibility

No path is opened without an explicit host callback. Empty skills and tools have distinct descriptions; names and descriptions remain safe text.

## Styling variables

Set public variables on an ancestor. Defaults preserve source geometry and inherit Design Core semantic colors. The theme dropdown and light/dark controls also apply to these results.
