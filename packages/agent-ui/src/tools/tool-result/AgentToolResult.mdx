# AgentToolResult

Generic and normalized tool results, plus a host registered view.

## Usage

Pass exact input/output/error capture and, optionally, a normalized detail. Tool-name detection and registry lookup belong to the host. The optional view snippet renders a registered result only when there is no captured error.

<Source code={Basic} language="tsx" />

## Anatomy

The shared Design Core detail renders shell output, file reads, edits/diffs, search matches, unavailable data, raw capture and capture warnings. A registered host snippet replaces only its formatted result.

## Behavior and accessibility

The view only presents capture; it never runs a tool. Raw capture remains exact. File navigation goes through an explicit host callback. Desktop owns its App registry and can pass App-backed views through this snippet; this package has no App dependency.

## Styling variables

Set public variables on an ancestor. Defaults preserve source geometry and inherit Design Core semantic colors. The theme dropdown and light/dark controls also apply to these results.
