# Threads

JJ Store's grouped repository inbox, with a selected complete AgentChatScreen
and an optional resizable attached panel. The host owns all native authority.

## Usage

Open and retain `ThreadsController` in the host. Its read-only `ThreadsPort`
enumerates registered homes and snapshot-bound pages; it cannot activate code.
Retain conversation controllers by `threadKey({home,id})`, including drafts and
exact unknown requests. The snippet receives navigation to compose in the
existing chat header, avoiding a second toolbar.

<Source code={Basic} language="tsx" />

## Anatomy

The left region has search, All/Active/Archived views, grouped repository rows,
independent retry and bounded continuation. The centre receives the existing
complete conversation. The optional attached right panel retains the AppShell
header, close, resize and compact replacement behavior.

## Behavior and accessibility

Selections carry both home and thread identity. Search applies to loaded rows;
More Threads and Load more repositories explicitly continue bounded reads.
Failures remain independent per home and report through the host callback.
Opening a conversation never sends. Create and code navigation are explicit
callbacks; missing capabilities disable their controls. Active excludes archived
and tombstoned records; Archived reflects the host's recorded status.

The list supports pointer dragging, arrow-key resizing, Home/End and double-click
reset, with widths between 224px and a viewport-dependent maximum of 480px.
The nested inbox switches to AppShell's mobile stages below 704px of available
body width. Host selections reveal the conversation without a second click in
the list. Closing the attached panel restores focus. The supplied conversation retains the existing
view switch, composer footer and Send semantics.

## API

<ArgTypes of={Stories} />

`ThreadsPort.homes` returns registered identities, never raw paths. `read`
receives home, opaque cursor, limit and abort signal. A page must match its home
and snapshot; duplicate row IDs, repeated cursors and more than 1000 loaded rows
per home are rejected. Four concurrent reads and batches of twenty homes bound
directory fanout. Optional subscriptions request refresh without mutating.
`drain()` waits for owned reads and `close()` aborts and releases subscriptions.

## Composition

Use `conversation(identity,navigation)` to mount the public `AgentChatScreen`
with a retained controller and the navigation snippet in its header actions.
Use `details` for host-provided contributors, settings or reply context; control
it through `detailsOpen`. These slots do not grant metadata or execution access.
The package never imports Repository UI or native transports. This inbox slice
does not yet qualify native reply/reaction/settings flows or execution in a
different repository from the conversation's metadata home.
